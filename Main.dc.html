Modular tactile pods for existing grippers

You build the robot.We build the touch.

Dermis is a modular tactile sensing kit for existing robot grippers and hands. Place sensing pods where contact matters, replace individual pods when they wear out, and verify each replacement before the robot goes back to work.

01The problem

Adding tactile sensing often becomes its own engineering project.

Teams have to choose sensors, design electronics, mount them, calibrate them and maintain them. When one sensing element wears out or fails, replacement can mean more integration and recalibration work.

Contact-heavy work still needs touch.

On tasks like key removal and plug insertion, policies that use touch have been shown to outperform vision-only setups. That is why teams want sensing on grippers — and why the integration and maintenance cost matters.

02Idea

Place a pod. Replace that pod.

Dermis turns tactile sensing into a replaceable component instead of a custom sensing stack. We are not building the robot hand. We are building the touch layer teams add to the grippers they already have — and swap one location at a time when a pod wears out.

The loop

Attach. Verify. Resume.

Attach pods to an existing gripper, verify them, then sense. When one location wears out, replace that pod, verify it, and resume.

What makes it different

The hassle is not finding a sensor. It is deploying and maintaining one.

01

Verify every replacement

After replacing a pod, run a defined calibration and verification check before returning the robot to operation. Dermis is being designed so that check is repeatable, not a one-off lab procedure.

02

Replace one pod

If one sensing location fails, replace that pod instead of replacing or rebuilding the entire sensing assembly.

03

Fits existing hardware

One sensor architecture, task-specific mounts. We are starting with selected grippers and expanding compatibility as we validate deployments.

04

A deployable kit, not another custom integration

Pods, a hub, task-specific mounts, and software for recording and verifying tactile data — so sensing is not another custom stack the team has to own.

04Product

The Dermis pod kit.

Existing gripper, Dermis pods, a replacement workflow, and verification. Starting with robotics teams working on contact-heavy manipulation such as gripping, insertion and delicate handling.

Sensor pods

Small, swappable tactile patches. Magnetic silicone skin over a magnetometer and an IMU on each pod.

  • Prototype today: pressure, contact location, and temperature
  • Place pods only where contact matters on the gripper
  • If one location fails, replace that pod instead of the whole assembly
  • In development: shear, slip detection, and per-pod electronics that store calibration

Grippers first

The v1 product is an existing gripper plus Dermis pods, with a replacement and verification workflow.

  • Task-specific mounts for selected grippers first, then more as we validate deployments
  • Not a new robot hand from Dermis — you keep the hardware you already run
  • Professor Dantu at UB has agreed to pilot on inspection robots once this version is ready
  • We are also testing the same sensing architecture for human demonstration collection

Hub & firmware

An ESP32 hub reads the pods over SPI today. Firmware is C/C++ on ESP-IDF.

  • Live streaming from the 4-pod prototype to a visualization dashboard
  • Custom PCBs designed in KiCad
  • Next: a small MCU on each pod so any pod works in any slot
  • Built so a swap is a part change, not a new electronics project

Software

Python for calibration and processing, live streaming over WebSocket, recordings in JSON.

  • Live dashboard of pressure, contact location, and temperature
  • Calibration and verification after a pod is replaced — in development
  • A pipeline from sensor readings to a view a team can watch and record
  • Local-first: no account and no cloud required to run a session
